## 三、图片风格统一规范

为确保全站图片视觉一致性，生成时请遵循以下规范：

| 维度 | 要求 |
|------|------|
| **整体风格** | 写实摄影风格，拒绝插画/卡通/3D渲染 |
| **色温** | 偏冷色调（深青、暗蓝、银灰为主）|
| **Accent 色** | 可少量使用暗金色/琥珀色作为点缀，与网站主题呼应 |
| **光线** | 自然光或科技感冷光源，避免暖黄/橙色主导 |
| **人物** | 所有配图建议无人物或仅有远景背影，保持专业感 |
| **背景** | 干净简洁，避免杂乱元素干扰主体 |
| **分辨率** | 不低于 1200px 宽，确保视网膜屏清晰 |
| **格式** | 照片类保存为 JPG（质量 90%），透明元素用 PNG |
